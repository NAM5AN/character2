# Report Style Guide

## 목표

최종 결과는 연구 노트나 근거표가 아니라, 캐릭터의 내적 작동 방식을 이해하게 만드는 자연스러운 한국어 해석문이어야 한다.

## 문장 구조

가능하면 주요 문단은 다음 흐름을 가진다.

1. 관찰 가능한 행동 또는 반복 패턴
2. 그 행동을 만드는 숨은 기준·욕구·보상
3. 기준이 깨지거나 뒤집히는 조건
4. 관계나 갈등에서 생기는 결과

이를 번호처럼 드러내지 말고 산문으로 연결한다.

## 좋은 예

`가까운 사람의 문제에는 스스로 개입해 해결하려는 경향이 강하다. 중요한 것은 단순히 도움이 되는 것보다 자신이 상황을 이해하고 손댈 수 있는 위치에 있다는 감각에 가까워 보인다. 그래서 상대가 도움을 거절할 때는 선택 차이보다 자신의 역할이 필요하지 않다는 신호처럼 받아들일 가능성이 있다. 다만 관심 밖의 일에는 같은 개입성이 나타나지 않는다면, 이 특성은 전반적인 통제욕보다 친밀감과 책임감이 결합될 때 강화되는 성향으로 보는 편이 맞다.`

## 나쁜 예

`책임감이 강하고 가까운 사람을 잘 챙긴다. 자기 방식이 확실하며 갈등 상황에서도 적극적으로 행동한다.`

이 문장은 원자료를 분류한 수준이며 숨은 메커니즘이 없다.

## 섹션별 작성 기준

### 겉으로 보이는 모습

외형·키·소지품을 다시 소개하지 않는다. 다른 사람이 반복적으로 경험하는 태도와, 그 태도 뒤의 실제 판단 사이의 간극을 설명한다.

### 실제 내면

유지하고 싶은 자기상, 관계 상태, 통제감, 보상 감각과 무엇이 그것을 위협하는지를 중심으로 쓴다.

### 갈등 방식

`감지 기준 → 초기 대응 → 임계점 → 고집/개입 강화 → 물러나는 예외`의 연결이 보여야 한다.

### 애정 표현

행동 목록이 아니라 친밀감 속에서 무엇을 확인받고 싶은지, 보호와 통제·경계가 어디서 맞닿는지 해석한다.

### 핵심 가치 / 욕망 / 두려움

표면 목표보다 한 단계 아래의 심리적 기능을 쓴다.

예:

- 나쁨: `자유`
- 좋음: `자기 선택이 타인의 판단에 의해 수정되지 않는 상태를 지키려는 욕구`

### 쉽게 오해받는 부분

겉에서 보이는 의미와 실제 내부 기능의 차이를 설명한다.

### 캐릭터의 모순

상반된 두 행동을 나열한 뒤 끝내지 않고, 둘이 같은 욕구에서 갈라져 나온 이유를 설명한다.

### AI가 발견한 흥미로운 지점

오너가 이미 명시한 설정이 아니라 여러 단서를 연결했을 때 새로 보이는 속내·맹점·관계의 숨은 기대를 우선한다.

### 통합 상세 해석

최소 세 가지 이상의 새롭게 도출된 연결을 자연스럽게 포함한다. 항목을 다시 요약하지 말고 중심 원리에서 관계·갈등·친밀감·자기인식이 어떻게 파생되는지 하나의 흐름으로 쓴다.

## 문단

- 문장 수를 맞추려고 기계적으로 나누지 않는다.
- 논점이 실제로 전환될 때만 새 문단을 만든다.
- 앞 문단의 결론이 다음 문단의 출발점이 되게 한다.

## 표현 강도

- 강한 근거: 자연스럽게 단정
- 중간 근거: `~에 가깝다`, `~로 읽힌다`
- 잠정 가설: `~일 가능성이 있다`, `~로 볼 여지가 있다`

## 사용자에게 노출하지 않는 것

- 질문 번호
- 점수·퍼센트
- 슬라이더/다이얼/선택지 명칭
- 분석 과정의 내부 단계
- 근거 ID
- confidence 점수
- `프로필에서`, `답변에서`, `AI가 분석한 결과` 같은 출처 표현
