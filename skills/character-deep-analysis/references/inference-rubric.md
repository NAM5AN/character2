# Inference Quality Rubric

각 주요 해석을 최종 리포트에 넣기 전에 아래 기준으로 평가한다.

## 1. Evidence Strength — 근거 강도

- 0: 근거 없음 또는 한 장면뿐
- 1: 같은 유형의 근거 2개
- 2: 서로 다른 자료 영역의 근거 2개 이상
- 3: 여러 영역에서 반복되고 예외까지 설명 가능

## 2. Specificity — 캐릭터 고유성

- 0: 누구에게나 붙일 수 있는 문장
- 1: 일부 구체성이 있으나 일반적
- 2: 특정 행동·관계 조건과 연결됨
- 3: 이름을 다른 캐릭터로 바꾸면 성립하기 어려운 수준

## 3. Latent Depth — 해석 깊이

- 0: 사실 재서술
- 1: 성격 라벨 부착
- 2: 행동을 만드는 기준·보상·위협을 설명
- 3: 숨은 욕구·맹점·자기상·관계 메커니즘까지 연결

## 4. Counter-evidence Robustness — 반례 내성

- 0: 반례를 무시함
- 1: 반례가 있지만 설명하지 못함
- 2: 조건 차이로 대부분 설명 가능
- 3: 반례 자체가 더 큰 원리를 강화함

## 5. Inference Distance — 추론 거리

- 0: 근거 없는 설정 창작
- 1: 가능한 해석이나 비약 큼
- 2: 자료에서 한 단계 추론
- 3: 여러 단서가 자연스럽게 같은 방향을 지지

## 6. Predictive Value — 행동 예측력

- 0: 이후 행동을 전혀 예측할 수 없음
- 1: 넓은 성향만 예측
- 2: 특정 관계·상황에서의 반응을 예측 가능
- 3: 기준이 유지/붕괴하는 조건까지 예측 가능

## 통과 규칙

강한 주장으로 최종 리포트에 넣으려면:

- Evidence Strength ≥ 2
- Specificity ≥ 2
- Latent Depth ≥ 2
- Inference Distance ≥ 2

그리고 총점 12점 이상을 권장한다.

이 최소 기준은 "포함할지"를 정할 뿐이다. 리포트의 핵심 가치는 깊이이므로, 통과한 해석 중 가능한 한 많은 수가 Latent Depth 3(숨은 욕구·맹점·자기상·관계 메커니즘까지 연결)과 Inference Distance 3(여러 단서가 같은 방향을 지지)에 도달하도록 목표한다. 최종 서술에서는 depth 2에서 멈춘 한 단계 해석보다, depth 3에 가까운 여러 겹 해석을 앞세워 쓴다.

총점이 낮지만 흥미로운 가설은 `가능성이 있다`, `이렇게 읽힐 수 있다` 수준으로만 사용한다.

## 자동 탈락

다음은 점수와 상관없이 제외한다.

- 오너 정정과 정면 충돌
- 새 과거 사건·트라우마·진단을 만들어야 성립
- 질문 번호나 점수 자체를 성격 특성처럼 사용
- 원문 한 문장만 바꿔 쓴 수준
- 같은 결론을 다른 표현으로 반복
