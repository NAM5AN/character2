# Thematic Coding Reference

## 목적

원자료의 표현을 그대로 옮기지 않고, 관찰 가능한 행동과 판단을 짧은 의미 단위로 바꾸는 단계다. 이 단계에서는 심리 원인을 아직 확정하지 않는다.

## 입력 단위

- 설정에 명시된 반복 행동
- 관계에 따라 달라지는 행동
- 상황 질문에서 선택한 반응
- 선택 이유
- 조건 변화 시 달라진 선택
- 오너의 정정과 보충

## 좋은 Semantic Code의 조건

- 원문보다 짧다.
- 행동 또는 판단 기준이 보인다.
- 심리 진단이나 원인 추정이 섞이지 않는다.
- 다른 코드와 비교·결합할 수 있다.

예:

- `직접 해결하려 함`
- `친밀한 상대에게 개입 범위가 넓어짐`
- `타인이 자기 결과물을 다시 수정하는 것을 꺼림`
- `흥미가 높아지면 기존 책임 우선순위가 흔들림`
- `표정이나 반응을 명시적 말보다 먼저 신호로 사용함`

## 피해야 할 코드

- 너무 표면적: `화냄`, `좋아함`
- 너무 추상적: `자유를 추구함`, `통제 욕구`
- 진단적: `회피형`, `강박적`
- 원문 복사: 긴 대사나 설명을 그대로 코드로 사용

## 관계·조건 보존

같은 행동도 조건이 다르면 별도 코드로 남긴다.

예:

- `낯선 상대의 문제에는 관찰 후 개입`
- `가까운 상대의 문제에는 즉시 개입`

이를 `남을 잘 도와줌` 하나로 평탄화하지 않는다.

## 수치형 응답 처리

숫자는 사용자 결과에 남기지 않고 의미만 보존한다.

- 극단값 → `매우 강하게 기울어짐`
- 중간보다 한쪽 → `한쪽을 선호하지만 절대적이지 않음`
- 중앙 → `상황에 따라 양쪽 가능`

숫자 자체보다 **방향, 강도, 임계점**을 기록한다.
