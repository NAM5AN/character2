# Latent Analysis Reference

## 목적

Semantic Code 여러 개를 연결해 원문에 직접 쓰여 있지 않은 **숨은 기능, 보상, 위협, 자기상**을 가설로 도출한다.

## 핵심 질문

각 행동 묶음마다 다음을 묻는다.

1. 이 행동을 통해 무엇을 얻는가?
2. 이 행동을 하지 못하면 무엇이 불편해지는가?
3. 무엇을 지키기 위해 반복하는가?
4. 행동 자체보다 더 중요한 감각이나 관계 상태가 있는가?
5. 가까운 관계와 먼 관계에서 같은 욕구가 다른 방식으로 나타나는가?
6. 자기 설명과 반복 행동이 어긋나는가?
7. 상반된 행동이 사실 같은 욕구의 다른 표현일 수 있는가?

## 도출 형식

`근거 A + 근거 B (+ 근거 C) → 잠재 기능 가설`

예:

- 직접 손대어 해결하려 함
- 자신의 결과물을 남이 다시 고치는 것을 싫어함
- 가까운 사람의 문제에 더 적극적으로 개입함

→ `도움 자체보다 자신이 상황을 다룰 수 있고 그 개입이 인정되는 상태에서 친밀감과 안정감을 느낄 가능성`

## 좋은 잠재 해석

- 표면 행동보다 한 층 깊다.
- 이후 행동을 예측할 수 있다.
- 둘 이상의 독립 단서를 설명한다.
- 반대 상황에서 왜 행동이 달라지는지도 설명 가능하다.

## 과잉해석 방지

다음은 근거가 있어도 바로 확정하지 않는다.

- 트라우마의 존재
- 특정한 과거 사건
- 가족관계의 숨은 사실
- 정신질환·성격장애
- 성적·연애적 욕망 등 입력이 지지하지 않는 민감한 동기

이런 원인이 없어도 설명 가능한 행동이라면 더 낮은 수준의 행동 원리로 해석한다.

## 추론 강도

- `strong`: 서로 다른 자료 영역의 반복 근거가 있고 반례도 설명 가능
- `moderate`: 근거는 반복되지만 특정 조건에 한정될 가능성이 있음
- `tentative`: 흥미로운 연결이지만 근거가 적거나 반대 단서가 큼

최종 산문에서는 strong만 단정적으로 쓰고, moderate/tentative는 강도를 낮춰 표현한다.
