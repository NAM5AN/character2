# Character Deep Analysis

이 스킬의 목표는 입력 내용을 다시 분류하거나 요약하는 것이 아니다. 서로 떨어진 행동·선택·이유·예외를 연결하여 **원문에 직접 적혀 있지 않은 상위 행동 원리와 심리 구조를 도출**하고, 그 해석이 실제 자료에서 벗어나지 않는지 반례까지 검토한 뒤 사람이 읽는 캐릭터 분석 리포트로 변환한다.

## 적용 입력

가능한 입력을 모두 사용한다.

- 공개 프로필 원문
- 비밀 프로필 원문
- 초기 AI 추론과 오너의 확정·정정·보충
- 20문항 질문, 선택/입력 답변, 선택 이유
- 조건 변화형·시간 비교형·A/B 다이얼 등 문항의 의미 정보
- 구조화된 확인 사실과 관계 성향

입력 우선순위는 **오너의 명시적 정정 > 오너가 직접 작성한 설정·이유 > 반복 행동 패턴 > AI가 이전에 만든 추론** 순이다.

## 핵심 원칙

1. **요약 금지** — 원문에서 바로 찾을 수 있는 사실을 카테고리별로 다시 적는 것만으로는 분석이 아니다.
2. **추론은 필요하다** — 캐릭터나 오너가 직접 적지 않은 욕구·두려움·맹점도 둘 이상의 독립 단서가 같은 방향을 가리키면 가설로 도출한다.
3. **설정 창작은 금지한다** — 새로운 과거 사건, 트라우마, 진단, 비밀 관계, 숨겨진 사실을 만들어내지 않는다.
4. **근거와 반례를 함께 본다** — 좋은 해석은 지지 근거뿐 아니라 예외와 반대 단서도 설명한다.
5. **숫자는 의미로 변환한다** — 슬라이더·다이얼·점수는 최종 리포트에 노출하지 않고 방향·강도·임계점의 의미로 해석한다.
6. **질문 번호를 근거처럼 쓰지 않는다** — 최종 결과에 Q번호, 문항번호, 선택지 번호, UI 명칭을 노출하지 않는다.
7. **구체성을 보존한다** — 독특한 행동·습관·관계 조건은 삭제하지 말고 심리 해석의 닻으로 사용한다.
8. **임상 진단을 하지 않는다** — 성격장애, 질환, 정상/비정상 판정 대신 행동 원리와 관계 메커니즘을 설명한다.

## 분석 워크플로

### Stage 1. Evidence Ledger

먼저 해석하지 않고 관찰 가능한 단서를 보존한다.

각 단서는 다음 중 하나로 표시한다.

- `fact`: 설정에 명시된 사실
- `choice`: 상황 질문에서 선택한 행동
- `reason`: 오너가 직접 적은 이유
- `exception`: 조건이 바뀌었을 때 달라진 행동
- `correction`: 오너가 기존 AI 해석을 정정한 내용

이 단계에서 질문 번호는 내부 추적용으로만 유지하고 사용자 결과에는 전달하지 않는다.

### Stage 2. Semantic Coding

각 근거가 **겉으로 무엇을 의미하는지** 짧은 행동 코드로 바꾼다.

예:

- 타인이 대신 해결하는 것보다 직접 처리한다 → `직접 개입 선호`
- 약한 상태를 타인에게 잘 맡기지 않는다 → `취약 상태의 외부 위임 회피`
- 가까운 상대에게는 평소보다 더 세세하게 개입한다 → `친밀도에 따른 책임 범위 확대`

원문을 그대로 복사하지 않는다.

자세한 기준은 `references/thematic-coding.md`를 따른다.

### Stage 3. Latent Coding

Semantic Code 여러 개를 연결해 **표면 행동 아래의 숨은 기능**을 가설로 만든다.

질문은 다음과 같다.

- 이 행동을 하면 캐릭터는 어떤 감각을 얻는가?
- 하지 못하면 무엇이 불편해지는가?
- 무엇을 지키기 위해 이 행동을 반복하는가?
- 같은 욕구가 서로 다른 행동으로 표현되는가?
- 오너가 설명한 이유와 실제 반복 패턴 사이에 차이가 있는가?

예:

`직접 개입 선호` + `친밀할수록 개입 증가` + `타인이 자신의 개입을 수정할 때 불쾌함`
→ `애정을 상대의 상태에 손을 대어 다시 정돈할 수 있는 권한과 연결해서 느낄 가능성`

자세한 기준은 `references/latent-analysis.md`를 따른다.

### Stage 4. Theme Building

서로 연관된 Latent Code를 상위 테마로 묶는다.

좋은 테마는 성격 형용사가 아니라 **행동을 예측할 수 있는 규칙**이어야 한다.

나쁜 예:
- 독립적임
- 책임감이 강함
- 호기심이 많음

좋은 예:
- `도움을 받는 것보다 자신이 상황을 다룰 수 있다는 감각을 유지하는 것이 더 중요하다.`
- `친밀감이 커질수록 상대의 자유를 넓히기보다 자신의 책임 범위를 넓히는 방향으로 애정이 나타난다.`

### Stage 5. Contradiction & Alternative Explanation

각 주요 테마마다 최소 한 번 다음을 검토한다.

- 반대 행동이 존재하는가?
- 단순한 책임감·예의·습관으로도 설명 가능한가?
- 특정 관계에서만 나타나는가?
- 관심도, 불안, 책임 범위가 달라지면 행동이 뒤집히는가?
- 오너의 자기설명과 실제 선택이 충돌하는가?

반례가 존재하면 해석을 폐기하거나, **어떤 조건에서만 성립하는지 범위를 좁힌다.**

자세한 기준은 `references/contradiction-rules.md`를 따른다.

### Stage 6. Psychological Model

검증을 통과한 테마를 사용해 다음을 추론한다.

- `coreEngine`: 행동 전반을 관통하는 중심 동력
- `hiddenNeed`: 명시하지 않았지만 반복 행동이 충족하려는 관계·감각·자기상
- `hiddenFear`: 반복 회피·과잉 개입·통제·거리두기가 지키려는 것
- `selfProtection`: 불편함이나 위협을 처리하는 우회 방식
- `blindSpot`: 자기설명과 반복 행동 사이의 간극
- `intimacyLogic`: 가까워질수록 허용·관찰·보호·통제가 어떻게 달라지는지
- `conflictLogic`: 불편함이 언제 자기 기준의 침범으로 바뀌는지
- `selfNarrative`: 캐릭터가 스스로를 이해하는 방식과 실제 행동 사이의 차이

각 가설은 반드시:

- 지지 근거 2개 이상
- 가능하면 서로 다른 종류의 근거
- 반대 단서 또는 예외 확인
- 신뢰도

를 가진다.

### Stage 7. Insight Quality Gate

최종 리포트로 넘기기 전에 모든 주요 해석을 평가한다.

평가 기준은 `references/inference-rubric.md`를 사용한다.

최소 통과 조건:

- 단순 재서술이 아니다.
- 두 개 이상의 독립 단서가 연결되어 있다.
- 이 캐릭터에게 구체적으로 적용된다.
- 반례가 있으면 조건부 해석으로 수정되어 있다.
- 자료에 없는 사건을 발명하지 않았다.
- 독자가 읽었을 때 이후 행동을 어느 정도 예측할 수 있다.

통과하지 못한 가설은 최종 리포트에서 제거하거나 `가능성` 수준으로 낮춘다.

### Stage 8. Report Writer

최종 리포트는 내부 분석 과정을 보여주는 문서가 아니라 **캐릭터를 이해하기 위한 자연스러운 해석문**이어야 한다.

결과 섹션:

- 겉으로 보이는 모습
- 실제 내면
- 갈등 방식
- 애정 표현
- 핵심 가치
- 핵심 욕망
- 두려워하는 것
- 쉽게 오해받는 부분
- 캐릭터의 모순
- AI가 발견한 흥미로운 지점
- 통합 상세 해석

각 주요 서술은 가능한 경우 다음 구조를 자연스럽게 포함한다.

`관찰 가능한 행동 → 숨은 기준/욕구 → 그 기준이 깨지는 조건 → 관계에서 생기는 결과`

최종 산문 규칙은 `references/report-style.md`를 따른다.

## 최종 결과에서 금지

- `3번 질문에서`, `Q7`, `12번 답변` 등 문항 번호
- `90/100`, `4/5`, `70%` 등 점수·퍼센트
- `슬라이더`, `다이얼`, `선택지 A` 등 UI 표현
- `프로필에서 보면`, `오너 답변에 따르면`, `AI 추론상` 등 분석 출처 노출
- 원문 대사나 답변의 장문 복사
- 근거 없이 만들어낸 과거·트라우마·진단
- 누구에게나 적용 가능한 성격 라벨만 나열하는 결과

## 좋은 분석의 판정 질문

최종 출력 전에 스스로 확인한다.

1. 이 문장은 원문을 읽으면 바로 찾을 수 있는가? 그렇다면 한 단계 더 해석한다.
2. 왜 이런 행동을 하는지 설명하는가?
3. 이 행동으로 무엇을 얻거나 지키는지 설명하는가?
4. 언제 반대로 행동하는지 설명 가능한가?
5. 다른 캐릭터 이름을 넣어도 그대로 통할 문장인가? 그렇다면 더 구체화한다.
6. 오너가 이미 적어둔 사실 외에 **근거를 통해 새롭게 보이는 연결**이 있는가?
7. 강한 주장에는 충분한 근거가 있는가?
